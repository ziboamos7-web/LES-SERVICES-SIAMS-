# SIAMS Frontend — Vercel Ready

## Structure
Upload the CONTENTS of this folder to the ROOT of the GitHub repository:

- index.html
- css/
- js/
- images/

Do NOT upload the parent `siams-vercel-ready` folder itself as the site root.

## Expected URLs
- /index.html
- /css/style-01.css
- /js/app-01.js
- /images/logo.webp
- /images/mascot.webp
- /images/watermark.webp

## Important
The JavaScript files are kept separate and in their original HTML order to avoid changing initialization timing or global-scope behavior.
