# Parcours marchand SIAMS

1. Le visiteur découvre SIAMS.
2. Il parcourt l'onboarding.
3. Il consulte les informations de partenariat.
4. Il contacte le service client.
5. Le service client lui transmet un code.
6. Il saisit le code.
7. SIAMS vérifie le code.
8. Il crée son compte marchand.
9. Il valide son OTP e-mail.
10. Le code est activé sur sa boutique.
11. Il accède au dashboard.
